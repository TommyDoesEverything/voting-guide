# Adding an election

Each election lives in its own folder, `elections/<id>/`, and is listed in `elections/index.js`. The site's code stays the same; only the data changes.

## 1. Register it

Add an entry to `elections/index.js`:

```js
{
  id: "vancouver-2030",          // folder name; also the ?election= value in links
  name: "Vancouver General Local Election 2030",
  short: "Vancouver 2030",
  place: "Vancouver, BC",
  type: "Municipal",
  date: "2030-10-19",            // voting day
  close: "20:00",                // polls close; after this it is shown as a past election
  results: false,                // set true once results.js exists
}
```

There's no default to set. The site opens on the earliest election whose voting day hasn't ended yet, switching at midnight after voting day, and on the most recent one once all are over.

## 2. Create the data folder

Copy `elections/burnaby-2026/` as a starting point and replace its contents.

| File | What goes in it | Required |
| --- | --- | --- |
| `profiles.js` | Every candidate's official statement, ideally generated by a script from the official source (see `scripts/burnaby-2026/`). | Yes |
| `guide.js` | Everything else: the `election` block (offices, dates, voting-day facts), sources, parties, per-candidate key points and notes, signature tags, issues. | Yes |
| `opinions.js` | Attributed arguments for and against. | No |
| `polls.js` | Published polling, copied exactly. | No |
| `ridings.js` | Boundary shapes for "Find my riding" (see `scripts/bc-2026/fetch_boundaries.py`). Only for elections with `chooseOffice.finder`. | No |
| `results.js` | Official results (template: `elections/_template/results.example.js`). | After voting day |

The `election` block in `guide.js` drives the Overview page and labels across the site, so nothing is hard-coded. `offices` defines the races and how many people each voter can pick. If each voter is in just one race (a riding), add `chooseOffice` so the guide asks which one; give it a `finder` block (see `elections/bc-2026/guide.js`) to let people find it from an address or their location.

## 3. Check it

```sh
node scripts/check_data.js
```

The check validates every registered election: candidate IDs, source IDs, offices, opinion items, results, and the no-dashes rule. Then open `index.html?election=<id>` at phone width.

## 4. After voting day

1. Add `results.js` with the official counts, copied exactly from the official declaration.
2. Set `results: true` in `elections/index.js`.

Once polls close, the guide switches to past tense automatically. It hides voting instructions and My ballot, and shows a Results tab and a "Who was elected" summary. The campaign content stays as it was, as a record.

Follow [CONTRIBUTING.md](../CONTRIBUTING.md) for every election: candidates in their own words, sources for everything, opinions attributed.
