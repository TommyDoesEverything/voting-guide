# Research notes (provenance)

These are the original AI chat transcripts (Gemini) used to make the first prototype in `archive/`. They're kept to show how the project started. **They are not sources.** Fact-checking found several errors in them, including invented poll numbers, platforms attributed to the wrong candidates, and wrong slate rosters.

Every fact on the live site comes from the sources listed in `data/guide.js` (also shown on the site's About page).
