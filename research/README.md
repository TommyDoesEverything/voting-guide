# Research notes (provenance)

- `gemini-chat-*.txt`: the original AI chat transcripts (Gemini) used to make the first prototype in `archive/`. They're kept to show how the project started. **They are not sources.** Fact-checking found several errors in them, including platforms attributed to the wrong candidates, wrong slate rosters, and region-wide poll figures presented as Burnaby's.
- `Media Release - BC Municipal Election Polling - October 7, 2026.pdf`: Leger's Vancouver CMA municipal poll (fieldwork Sept 23-30, 2026, in partnership with Postmedia). The guide cites Leger's public copy; this file is kept for reference. Burnaby results are on page 20.

Every fact on the live site comes from the sources listed in `data/guide.js` (also shown on the site's About page).
